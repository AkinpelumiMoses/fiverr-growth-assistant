# Fiverr Growth Assistant
An AI-assisted workspace for Fiverr sellers to analyse gigs, understand performance and plan practical improvements.

## Stack
Next.js 15 · React 19 · TypeScript · Tailwind CSS
Supabase and Gemini integration are planned for subsequent milestones.

## Local development
`npm install`
`npm run dev`

## Product integrity
Metrics are user-provided unless an authorised integration is explicitly added. The app does not fake engagement, automate clicks or searches, or promise Fiverr rankings or orders.

## Build milestones
1. Responsive dashboard and navigation
2. Seller profile and gig workspace
3. Manual performance tracking
4. Gig/profile audit workflows
5. Secure AI coach integration
6. Keyword and competitor research
7. Growth plans and deployment hardening
